# Discover and Specify the Product

1. Read `AGENTS.md` and the index in `docs/specs/README.md`.
2. Read existing specifications before changing them.
3. Talk with the requester to understand the problem, users, goals, scope, and constraints. Ask focused questions when an answer could materially change the specification.
4. Update the appropriate documents in `docs/specs/`. Separate confirmed facts, assumptions, and open questions; do not choose a tech stack or invent missing details.
5. If an important decision is made, record it using `docs/specs/decisions/000-template.md` as a reference.
6. Review consistency, acceptance criteria, and index links.
7. Summarize changed documents and any outstanding decisions or questions.

This workflow changes only agent documentation and specifications. Do not implement the application.
