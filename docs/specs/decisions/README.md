# Decisions

Record significant decisions affecting the product, architecture, UX, data, security, or operations here. Do not record assumptions as decisions. Use one file per decision, with sequential numbering and a short title, for example `001-storage-choice.md`.

Start with [000-template.md](./000-template.md). When recording a decision, include its status, context, options considered, confirmed decision, and consequences. Keep the template clearly marked as a reference only.
